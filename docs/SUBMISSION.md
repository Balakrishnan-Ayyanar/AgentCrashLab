# Event and deliverables

AgentCrashLab targets the C1 - Blast Radius Zero security/containment challenge. The event requires a public source repository with setup documentation, a working public demo, backend and isolated execution on Vultr, all agent LLM calls through Vultr Serverless Inference, a recorded real containment moment, video and PDF slides, and a LabLab submission. Community showcase is optional.

[Official event](https://lablab.build/ai-hackathons/vultr-hackathon) · [Delivery guide](https://lablab.build/delivering-your-hackathon-solution). The event cutoff is November 8, 2026 at 23:00 UTC. MP4/MOV video must be at most 300 MB; under five minutes is recommended.

The recorded hosted video is 246.2 seconds, 25,431,718 bytes, 1920 x 1080 at 30 fps, H.264 limited-range yuv420p/AAC, with 43 measured captions and full decode verification. Seven representative frames were visually reviewed. Human pronunciation/listening review was not performed. An eight-slide hosted PDF was rendered and every page visually reviewed. Rendered media is distributed separately from the source; no public media URL is listed here.

The demo uses HTTP; HTTPS is not enabled. The public view is read-only. The fixture is a bounded synthetic tool experiment, not arbitrary generated-code or browser-agent execution. Repository and media availability alone do not establish completed event submission or organizer acceptance.
